# Expense Tracker

A simple Python-based Expense Tracker to record, manage, and visualize expenses efficiently.  
This CLI-based application allows users to categorize expenses and analyze spending habits with a pie chart.

## 🚀 Features
- ✅ **Add Expenses** – Enter expense details with category & amount  
- ✅ **View Total Expenses** – Track total money spent  
- ✅ **Category-wise Breakdown** – Analyze spending patterns  
- ✅ **Pie Chart Visualization** – Graphical expense distribution using Matplotlib  
- ✅ **Data Persistence** – Stores expense records in a CSV file  

## 🔧 Technologies Used
- **Python** (Core logic)  
- **CSV** (Data storage)  
- **Matplotlib** (Graph visualization)  

## 📂 File Structure
```
Expense-Tracker/
│── expense_tracker.py  # Main script
```

## 📈 Setup & Usage
### Installation
Clone the repository:
```bash
git clone https://github.com/yourusername/Expense-Tracker.git
cd Expense-Tracker
```
Install dependencies:
```bash
pip install matplotlib
```
Run the program:
```bash
python expense_tracker.py
```

## 📊 How It Works
1️⃣ Run the script in a terminal.  
2️⃣ Choose from the menu options:  
   - Add a new expense  
   - View total expenses  
   - Display category-wise expenses  
   - Show all recorded expenses  
   - Generate a pie chart for visualization  

🗂 Data is automatically saved in `expenses.csv`.
